# Báo cáo đề tài 13

Tệp [`Bao-cao-De-13.docx`](Bao-cao-De-13.docx) là báo cáo tổng hợp triển khai website portfolio và các dịch vụ hạ tầng bằng Docker Compose. Sơ đồ kiến trúc trong báo cáo là hình minh họa được tạo theo cấu hình dự án.

## Trước khi nộp

- Bổ sung chính xác mã số sinh viên, lớp, giảng viên hướng dẫn và ngày demo trên bìa.
- Chạy stack theo hướng dẫn trong README gốc, sau đó chèn ảnh chụp thật vào các vị trí đánh dấu: website, phpMyAdmin, Prometheus Targets, dashboard Grafana, truy vấn LogQL, `docker compose ps`, security headers và GitHub với ba commit.
- Điền kết quả quan sát thực tế; không đánh dấu đạt nếu chưa chạy và xác minh thành phần đó.
- Không chụp hoặc commit `.env`, mật khẩu, token hay dữ liệu cá nhân không cần thiết.

Các ảnh gắn nhãn “ảnh chụp minh chứng” phải được lấy từ phiên chạy trên máy sinh viên; không dùng sơ đồ kiến trúc thay cho ảnh xác nhận dịch vụ hoạt động.
